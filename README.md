
# Klasifikasi E-Waste Berdasarkan Kategori dengan Metode Transfer Learining ResNet-50

Penelitian skripsi ini berfokus pada klasifikasi sampah elektronik (E-Waste) menggunakan metode transfer learning dengan arsitektur ResNet-50. Penelitian ini ditujukan untuk mengatasi keterbatasan pada studi terdahulu, seperti keterbatasan jumlah data, ketidakseimbangan kelas dataset (class imbalance), kecenderungan overfitting, serta penggunaan citra yang masih terbatas pada latar belakang putih (plain background).

## Tech Stack

**Language:** Python

**Deployment:** Streamlit Cloud


## Run Locally

Clone the project

```bash
    git clone https://github.com/kevinchristian24/Skripsi.git
```

Go to the project directory

```bash
    cd Skripsi
```

Install dependencies

```bash
    pip install -r requirements.txt
```

Start the server

```bash
    streamlit run file.py
```
